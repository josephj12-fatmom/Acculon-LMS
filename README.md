# Acculon LMS

A modern Learning Management System combining Schoology's course workflows with the **Attention Assessment** analytics suite (inspired by Performance Matters).

## 🚀 How to Host on GitHub Pages

1. Create a new public repository on GitHub named `acculon-lms`.
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` into the repository.
3. Go to your repository **Settings** -> **Pages**.
4. Under **Build and deployment**, select **Branch: main** and folder **/(root)**, then click **Save**.
